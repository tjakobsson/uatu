# Approved Mobile Design Reference

This directory now contains only static artifacts retained from the reviewed
mobile prototype:

- `refined.html`: the final screenshot gallery, viewable directly as a local file.
- `screenshots-refined/`: final screenshots and two interior-comparison crops.
- `refined-results.json`: the historical prototype verification report.

The runnable prototype, capture scripts, isolated dependencies, generated
workspace repositories, earlier alternatives, recordings, and logs were
removed after planning. Prototype servers and the additional Tailscale Serve
endpoint were stopped. No production implementation is present here.

The authoritative scope, behavior, safeguards, and implementation plan are in
[`openspec/changes/refine-mobile-hub-navigation/`](../../openspec/changes/refine-mobile-hub-navigation/).
Use these images for UX and visual reference only. Do not infer a production
iframe architecture, fake API, or resident-client guarantee from the captures.
The proposal preserves main's real routing and session lifecycles.

The report records the final browser-only prototype run: 82 checkpoints and
49 captures, including two baseline comparison crops. It is not evidence of
production implementation or a replacement for the proposal's validation gates.
